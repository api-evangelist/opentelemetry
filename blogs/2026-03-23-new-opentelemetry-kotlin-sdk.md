<p>Following a <a class="external-link" href="https://github.com/open-telemetry/community/issues/2975" rel="noopener" target="_blank">donation</a>
from Embrace and a
<a href="https://opentelemetry.io/blog/2025/kotlin-multiplatform-opentelemetry/">call for contributors</a>,
OpenTelemetry now has
<a class="external-link" href="https://github.com/open-telemetry/opentelemetry-kotlin" rel="noopener" target="_blank">a Kotlin SDK</a> in active
development.</p>
<p>The project is looking for contributors and folks who are interested in using
the library in their application.</p>
<h2 id="why-launch-opentelemetry-for-kotlin">Why launch OpenTelemetry for Kotlin?<a class="td-heading-self-link" href="#why-launch-opentelemetry-for-kotlin"></a></h2>
<p><a class="external-link" href="https://www.jetbrains.com/kotlin-multiplatform/" rel="noopener" target="_blank">Kotlin Multiplatform</a> (KMP)
allows running Kotlin code on many different platforms, such as browser, server,
and desktop environments. Traditionally Kotlin has been most popular on Android
and the JVM, but with the advent of KMP the number of folks using it to share
code between different platforms has been steadily growing.</p>
