The 2.32.0 release of the OpenTelemetry Java agent is now out and serves as the release candidate for 3.0 , which is targeted for October 2026 . Some behavior may still change before 3.0, but you can preview the new behavior now, before it becomes the default. 3.0 changes telemetry, configuration, and instrumentation defaults.
